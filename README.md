# Buzzer Sports Console

Admin management console for sports, competitions, and participant tracking, built with modern Angular.

## Tech Stack
* **Framework**: Angular 19+ (Standalone Components, Signals)
* **Styling**: SCSS, Design System based on Figma specifications
* **Language**: TypeScript

## Project Structure
* `src/app/layout/`: Global layout components (Sidebar, Header)
* `src/app/pages/`: Feature views (Sports Management Dashboard)
* `src/environments/`: Environment configurations for development and production

## Getting Started

1. **Clone the repository**
```bash
git clone [https://github.com/TUO_USERNAME/buzzer-sports-console.git](https://github.com/TUO_USERNAME/buzzer-sports-console.git)
cd buzzer-sports-console

```

2. **Install dependencies**
```bash
npm install

```

3. **Run development server**
```bash
npm start

```

Navigate to `http://localhost:4200/`.

## 🚢 Build & Production

To build the project for production:

```bash
npm run build

```
